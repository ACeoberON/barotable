⑥겹침 검사

같은 테이블·같은 날·확정 또는 방문 상태 예약 중 기존 시작 < 새 종료 그리고 새 시작 < 기존 종료이면 겹칩니다. 예: 10월 10일 T09는 19:00–20:30 예약이 있어서 19:30은 겹치고, 20:30은 겹치지 않습니다.

⑦두 손님이 같은 자리를 동시에 예약하면

손님 A와 B가 0.3초 차이로 같은 테이블·같은 시간을 예약합니다. A는 확인 후 저장 전에 2초 머뭅니다(느린 상황 재현). 누를 때마다 같은 자리의 이전 시연 예약은 지우고 새로 시작하므로, 두 버튼을 번갈아 눌러 비교할 수 있습니다.

① 트랜잭션 시작→② 테이블 행 잠금 (SELECT … FOR UPDATE)→③ 겹침 다시 확인→④ 저장→⑤ 커밋 (잠금 풀림)

손님요청 시각응답 시각걸린 시간결과

B는 A가 커밋할 때까지 기다렸다가 다시 확인해서 겹침을 발견하고 거절됐습니다. 같은 자리에 예약은 1건만 남습니다.

잠금이 없으면 B가 확인하는 순간 A가 아직 저장 전이라 둘 다 "겹침 0건"으로 보고 둘 다 저장됩니다. ⑤ 목록에서 같은 자리 중복을 확인한 뒤 아래 초기화를 누르세요.
